Cómo empezar

Un solo instalador y un asistente que te guía: en minutos estás vendiendo.

Descarga el instalador

QuindePOS-Setup.exe para Windows 10 y 11. Trae Java y la base de datos: no instalas nada más.

Instálalo

Deja la base de datos incluida (recomendado) o conéctalo a tu servidor MySQL/MariaDB.

Sigue el asistente

Tu negocio y logo, tipo de negocio, IVA, usuarios, impresora con ticket de prueba y productos (también desde Excel).

Activa la facturación

Con tu firma electrónica (.p12), en el mismo asistente o siguiendo la guía paso a paso.

El instalador aún no tiene firma digital: si Windows muestra «Windows protegió su PC», toca Más información → Ejecutar de todas formas.

# Linux, macOS o para compilarlo desde el código (Java 11 + MySQL/MariaDB)
git clone https://github.com/RiccijandroUpec/QuindePOS.git
cd QuindePOS
ant -f build_working.xml todo         # Quinde POS + facturación electrónica
start.bat                             # en Linux o macOS: ./start.sh
ant -f build_working.xml instalador   # arma el instalador de Windows (Inno Setup)

Preguntas frecuentes

Sistema de facturación gratis para Ecuador: lo que debes saber

¿Quinde POS es un sistema de facturación gratuito?

Sí. La versión para Windows es software libre (GPL v3): la descargas, la instalas y facturas sin pagar licencias, mensualidades ni costo por comprobante.

¿Sirve para la facturación electrónica del SRI en Ecuador?

Sí. Genera el XML con los esquemas oficiales del SRI, lo firma con tu firma electrónica, lo envía y consulta la autorización. Imprime el ticket con la clave de acceso y manda el PDF (RIDE) y el XML al correo del cliente.

¿Qué necesito para emitir facturas electrónicas?

Tu RUC habilitado para facturación electrónica en el SRI y una firma electrónica en archivo .p12, que se obtiene con una entidad certificadora autorizada. Puedes practicar primero en el ambiente de pruebas del SRI.

¿Funciona sin internet?

Sí. Puedes vender y emitir comprobantes sin conexión; las facturas se envían solas al SRI cuando vuelve el internet.

¿Hay versión para celular?

Sí, hay una app para Android 7 o superior. Es gratis en el ambiente de pruebas del SRI; para emitir facturas reales desde el celular se activa una licencia para el RUC de tu negocio.

¿Para qué negocios sirve?

Para tiendas, minimarkets, ferreterías, restaurantes, panaderías, farmacias y cualquier negocio del Ecuador que venda en mostrador y necesite caja, inventario y facturación.
